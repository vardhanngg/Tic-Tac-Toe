# Tic-Tac-Toe: Player vs Bot (Java)

A simple Tic-Tac-Toe game implemented in Java where you play against a bot.

## Features

- Player vs Bot gameplay
- The player uses 'x' and the bot uses 'b'
- Text-based interface in the console
- Choose to start first or second
- Detects wins, losses, and draws

## How to Play

1. Compile the Java files.
2. Run the `Main` class.
3. Choose whether to start first or second.
4. Enter your moves as row and column coordinates (e.g., `0,0`).
5. The bot will automatically make its move.
6. The game continues until there is a winner or a draw.

## Installation and Usage

1. Clone or download the repository.
2. Open a terminal in the project directory.
3. Compile the source files:

javac Main.java
Run the game:

java Main

Follow the on-screen instructions to play.
